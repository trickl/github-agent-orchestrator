# Target State

This document captures the desired, user-owned target state for the GitHub Agent Orchestrator.
It defines what the system should achieve, how it should behave, and the constraints that must
hold steady over time.

## Purpose

- Aligns development work with the user vision.
- Serves as the primary reference for gap analysis.
- Is updated by humans when intent, priorities, or constraints change.

## What to include

- Required capabilities and workflows.
- Quality bars, safety constraints, and guardrails.
- Operating assumptions (repos, permissions, time horizons).
- Success criteria that define “done.”
